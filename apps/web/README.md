# Kost Management — Web

React 19 SPA with TanStack Router, Tailwind CSS v4, and shadcn/ui.

## Dev

```bash
bun run dev
```

Runs on `http://localhost:3000`.

## Build

```bash
bun run build
```

## Tests

```bash
bun run test              # run all tests
bun run test -- --run <name>  # run single test
```
